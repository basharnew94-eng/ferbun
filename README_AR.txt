Fêrbûn — نسخة HTTPS مع وسيط آمن للنطق الكردي
================================================

لماذا هذه النسخة؟
- تتجنب CORS الناتج عن فتح HTML محليًا لأن الصفحة وواجهة /api/tts-audio على النطاق نفسه.
- مفتاح KurdishTTS محفوظ كمتغير بيئة في الاستضافة، وليس داخل HTML أو ملفات JavaScript.
- الصوت: Kurmanji، المعرّف الافتراضي kurmanji_236، مجموعة v4، والرد WAV.

النشر المقترح عبر Render (يتطلب حسابك وموافقتك؛ لم يتم النشر تلقائيًا):
1. ارفع محتويات هذا المجلد إلى مستودع Git خاص بك. لا تضع مفتاح API في المستودع.
2. في Render اختر New > Blueprint ثم اربط المستودع الذي يحتوي render.yaml.
3. عند مطالبتك بقيمة TTS_API_KEY، أدخل مفتاح TTS جديدًا من صفحة إعدادات API لدى KurdishTTS. لا تستخدم المفتاح الذي سبق نشره في المحادثة؛ اعتبره مكشوفًا وألغِه.
4. أنشئ الخدمة وانتظر اكتمال النشر. Render يمنح خدمة الويب عنوان HTTPS.
5. افتح رابط الخدمة؛ اختبر /health. يجب أن يعرض ttsKeyConfigured:true.
6. افتح التطبيق واضغط رمز السماعة على كلمة كردية.

حدود مهمة:
- لا يمكنني إنشاء الخدمة في حسابك دون أن تسجّل الدخول وتكمل الربط بنفسك. هذا المجلد جاهز للنشر، لكنه ليس رابطًا منشورًا بالفعل.
- يجب أن يكون مفتاح TTS صالحًا وأن يسمح اشتراكك بالصوت kurmanji_236 ضمن المجموعة v4. إذا أعادت الخدمة 400/403 فراجع قائمة الأصوات وخطة حسابك.
- نقطة النهاية عليها حد 20 طلبًا لكل عنوان IP في الدقيقة؛ هذا ليس نظام حسابات كاملًا، لذا لا تنشر رابط الخدمة على نطاق واسع دون حماية إضافية.
- النص المرسل محدود بـ500 حرف لكل طلب، بما يتوافق مع حد الخطة المجانية الموضح في توثيق KurdishTTS.
- لا يوجد مفتاح حقيقي في هذا المشروع.
